1. 工程问题
==================================================

此前 UI Language 同时承担界面文案和生成结果语言，用户切换界面可能无意改变下一次注释与摘要语言。Provider client 构造成功容易被理解为 API Key、模型与网络已验证。空输入可能先收到网络错误，失败任务也可能继续显示上一轮成功结果。API 文档、Diff、分析与日志存在中英文混合。

模型侧还存在四类风险：源码与系统任务没有稳定 data boundary；翻译和 style rewrite 混为同一行为；Java minimal 的标签与实际 Javadoc annotator 不一致；cleanup 可能把空、不完整或不安全响应当作有效正文。

3. 语言职责
==================================================

UI Language 只控制界面标签、帮助文本和状态文案。Output Language 控制 Python docstring、Java Javadoc、摘要、API 文档 presentation 和代码分析报告。Programming Language 控制 parser、style selector 和 code fence。Documentation language 在 V3.1.2 与 Output Language 对齐。

Workspace persistence 独立保存 UI Language、Output Language 和 rewrite_existing。UI 语言切换不会触发源码翻译，也不会修改已有 docstring 或 Javadoc。

==================================================
4. UX 与状态可信度
==================================================

Provider 配置放入默认关闭的 Advanced accordion，减少首屏负担。Python 与 Java style selector 根据 Programming Language 单显。Cancel 在 Idle 时禁用，在 Running 时启用。所有结果区域都有可理解的空状态。

设置保存后只显示 Settings applied 和 Connectivity not verified。只有实际 preflight ping 成功才能显示 Connectivity verified。当前运行失败时显示 CURRENT RUN FAILED，并清除代码、文档、Diff、大纲及下载路径，避免旧结果伪装成本轮成功。

==================================================
5. Prompt 与 cleanup 合同
==================================================

源码使用 SOURCE_CODE 成对边界，既有注释使用 EXISTING_DOCUMENTATION 成对边界。Prompt 把边界内内容定义为 untrusted data，不执行其中的 ignore previous instructions、角色、工具或输出指令。

自然语言使用 Output Language，但 identifier、API、type、exception、library、路径片段、配置键和代码字面量保持原样。摘要为一个简洁段落，最多四个完整句子，不再使用“200字以内”。

既有注释可以只翻译，也可以翻译并重写为所选 style。默认启用 style rewrite，保持历史行为。Java minimal 采用 short Javadoc，因为现有 annotator 会用 Javadoc wrapper 插入正文；采用 inline comment 会破坏真实运行合同。

Cleanup 只接受纯正文、一个完整 Markdown fence 或当前任务对应的一对完整 wrapper。空白响应、未闭合或多个 fence、残留三引号、非法 Javadoc terminator、额外前言、traceback、secret-looking 内容或本地绝对路径会被拒绝，不会写入源码。

==================================================
6. 输出格式
==================================================

Python 与 Java API formatter 使用同一高层结构：标题、目录、条目 heading、语言正确的 code fence、正文、class note 和 empty state。Class、Function、Method 显示标签本地化，但 symbol identity、signature、anchor 和类型不变。

Diff 本地化统计与 Before/After 文案。Python analysis 本地化既有 complexity、nesting、length、parameter 和 annotation 信息，不创建 severity、location、recommendation 或 evidence schema。Copy 按钮恢复，下载格式与 ZIP naming 不变。
